# 记事 Jishi

![记事图标](icon.svg)

一个无框架、无后端的轻量树状记事工具。下载 `index.html` 和 `icon.svg` 放在同一文件夹，打开页面即可使用。

## 功能
- Tab 新建子节点，Enter 新建同级节点，Delete 删除。
- 双击或右键“修改”编辑文字；右键复制、删除。
- 拖动节点调整层级和顺序；拖动主节点移动整图。
- Ctrl + 鼠标滚轮缩放，复位恢复默认比例。
- 七种主题，自动记住选择。
- 浏览器本地自动保存；打开/导出 JSON 文件。
- 支持的浏览器使用文件选择窗口保存到指定位置。

## 本地预览

```sh
python -m http.server 8080
```

访问 http://localhost:8080 。使用 localhost 或 HTTPS 可获得更完整的剪贴板和文件选择支持。文件选择器不可用时采用浏览器下载。

## 数据

笔记仅存储于当前浏览器 localStorage，不会上传 GitHub。发布文件仅包含虚构示例。数据未经加密，不宜存放真实密码或 API 密钥；请定期导出备份。更换浏览器或访问地址后，本地数据彼此独立。

## GitHub Pages

上传项目根目录文件后，在仓库 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 / (root)，保存即可发布静态页面。

## 图标

原创 SVG 图标以一枚中心节点向右分成两支，搭配蓝、奶黄与粉色，呼应树状记事与多巴胺主题。SVG 同时用于应用标识和浏览器标签图标。

## PWA 安装与离线

通过 HTTPS 或 localhost 打开网站，首次联网加载完成并显示“离线已就绪”后，可以点击顶部“安装”。Edge/Chrome 支持安装为独立窗口；iPhone/iPad 使用 Safari 分享 → 添加到主屏幕。首次打开需要联网，缓存完成后可离线启动与编辑。

发布时必须保留 manifest.webmanifest、sw.js 和 icons/ 目录。相对路径支持 GitHub Pages 的 /Xmind/ 子路径。新版本后台下载后，关闭所有应用窗口并重新打开即可应用更新；修改离线资源时同步递增 sw.js 的 CACHE 版本号。

笔记仍保存在当前站点的本地浏览器存储中，安装不会将 localhost 数据自动迁移到 GitHub Pages。请先从原页面导出 JSON，再在新地址打开文件。

## 单窗口限制

使用浏览器 Web Locks 独占锁，同一浏览器与同一站点下仅允许一个窗口操作。重复打开的标签页或 PWA 窗口显示阻止页，不读写笔记；关闭原窗口后可重新检测。不同浏览器、用户配置文件和设备互不限制。
